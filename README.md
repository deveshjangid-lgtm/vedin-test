# Airline Booking Website

Welcome to the new Airline Booking platform! This project has replaced the previous Cruise Line booking application.

## Core Pages (Phase 1)
1. **[Landing Page (`index.html`)](index.html)** - Features the hero banner, flight search widget, and popular destinations.
2. **[Flight Search (`search.html`)](search.html)** - Displays available flights, filters, and fare comparison.

## Build Order (Upcoming Phases)
- Fare Details Popup
- Traveller Details
- Seat Selection
- Add-ons & Booking Summary
- Payment Processing & Confirmation
- Manage Booking & Flight Status
- User Dashboard & Admin Panel

## How to use
Open `index.html` in your web browser to start exploring the airline reservation flow.
